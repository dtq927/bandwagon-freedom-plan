# 搬瓦工 Freedom Plan：$89/年免费换IP的限量套餐值不值，全系列套餐价格与购买避坑指南

搜“搬瓦工 Freedom Plan”的人，大概率是被一件事逼过来的：IP 被封了。搬瓦工平时换一次 IP 收 8.79 美元，被封一次换一次，一年下来这笔钱并不少。Freedom Plan 的卖点就一个——每两周免费换一次 IP，一年最多 26 次，按单次 8.79 美元的价格算，光这项权益理论上就值两百多美元。

但这个套餐的争议也不少：$89/年的价格能买到什么配置？线路是不是优化过的？跟 $99 的 THE PLAN 比谁更值？能不能买不到？这篇文章把这些问题一次讲清楚，顺带把搬瓦工目前在售的全部常规套餐和热门限量套餐整理成表格，价格均以当前官网页面为准。

## Freedom Plan 是个什么套餐

Freedom Plan 是搬瓦工在 2023 年 9 月 12 日上线的限量版套餐，配置如下：

| 项目 | 参数 |
| --- | --- |
| CPU | 2 核 |
| 内存 | 2 GB |
| 硬盘 | 40 GB SSD |
| 月流量 | 2 TB（2000 GB） |
| 端口带宽 | 2.5 Gbps |
| 机房 | 洛杉矶 DC2 AO（USCA_2，Coresite） |
| 价格 | $89/年，仅年付 |

两个必须知道的限制：

- **机房锁死在 DC2 AO**。这个套餐不支持迁移机房，下单后只能用洛杉矶 DC2 AO（Coresite）这一个位置。
- **CPU 占用受限**。按照官方服务条款，限量版套餐的持续 CPU 占用上限是单核的 30%，Freedom Plan 也不例外。拿它跑轻量建站、代理、开发环境没问题，持续高负载的活儿别指望。

换 IP 的规则是这样的：在 KiwiVM 面板里发起，每 14 天可以免费换一次，一年累计最多 26 次，一般一小时内生效。对比官方正常换 IP 收费 8.79 美元一次的价格，这个权益的账面价值相当高。

还有一个容易踩的坑，值得单独提醒：

> Freedom Plan 走的是普通 163 线路（三网直连），不是 CN2 GIA 优化线路。看中它是因为“免费换 IP”就没问题，但如果你要的是晚高峰也稳的回国速度，这个套餐的线路并不占优。

配置同级别、走 CN2 GIA-E 线路的限量套餐 CN2 GIA-E 40G 定价 $89.90/年，和 Freedom Plan 几乎同价，差异就在线路和换 IP 权益之间二选一。

## 想买 Freedom Plan，先搞清楚“限量”两个字

Freedom Plan 属于限量版套餐，长期处于售罄状态，只在官方不定期补货时放出。2023 年 9 月首发之后，当年 11 月双十一后有一波补货，之后每次补货的配置和价格都没变过：$89/年、DC2 AO 机房、每两周免费换 IP。

几个提高抢到概率的做法：

- **盯库存监控页**。搬瓦工有官方库存监控页（stock.bwg.net），所有套餐在各机房的实时库存一目了然，刷到 Freedom Plan 有货就是真的有货。
- **订阅补货通知**。官方的 Telegram 频道和补货邮件订阅（Google Groups）都会推送，补货一般在几分钟内被抢空。
- **提前把流程走熟**。注册好账号、想好付款方式，补货出现时直接下单，不要现注册现填。
- **用 30 天退款兜底**。搬瓦工所有套餐都支持 30 天内按政策退款，补货抢到后发现不合适，可以走退款，不用一次性赌对。

## 购买流程与常见问题

购买流程不复杂：点击套餐购买链接进入购物车，确认有货后选择计费周期、填写优惠码，注册或登录账号后付款，支持支付宝等多种付款方式。付款到账后 VPS 自动开通，在 KiwiVM 面板里可以重装系统、设置 rDNS、做快照，支持迁移机房的套餐也能在面板里直接切换。

**Q：Freedom Plan 被 IP 被封的人买，没被封的人需要吗？**

不是必需品。它的核心溢价就在免费换 IP 上，如果你用的 IP 一直很稳，同价位买 CN2 GIA-E 线路的套餐体验更好。

**Q：免费换 IP 有次数上限吗？**

每 14 天一次，一年最多 26 次，用 KiwiVM 面板操作，不用提工单。

**Q：Freedom Plan 以后能续费同价吗？**

可以。限量套餐的惯例是买到的用户保留原价续费权，这也是社区把这类套餐叫“传家宝”的原因。

**Q：限量套餐的 CPU 限制影响大吗？**

官方条款写明限量版套餐持续 CPU 占用为单核的 30%（THE PLAN 是 45%）。建站、代理、轻量开发够用，跑持续计算任务会受限。

**Q：买错了能退吗？**

所有套餐都有 30 天退款政策，Freedom Plan 在符合退款政策的条件下同样适用。

回到最初的问题：Freedom Plan 值不值，取决于你有没有“频繁换 IP”这个真实需求。有，它一年 26 次免费换 IP 的权益很难找到替代品；没有，$99 的 THE PLAN 2024 加 $10 就能拿到 CN2 GIA-E 线路和 18 个可切换机房，是更通用的选择。眼下 Freedom Plan 处于售罄状态，与其空等，不如先确认自己的需求属于哪一类，补货出现时直接下单。
